# 芽芽角色设计记录

日期：2026-10-28。角色名：芽芽；新版界面名称：码力芽芽。

## 设计目标与来源

为本地用量组件新绘制一只温和、可互动的叶片机器人。直接使用本项目 `MainWindow.xaml` 的 WPF 矢量基本形状、路径与渐变，不使用网上图片、现有角色截图、外部角色资源或新图形依赖。

这次处理不是给旧人物换色。旧图形的圆形猫头、白色口鼻区、胡须、红色项圈、铃铛和腹部口袋组合已从当前绘制中移除；保留的只是“完整身体、友好、会反馈状态”的通用产品需求。

## 新造型

- 薄荷绿圆角矩形头壳与深色电子屏，使用发光点眼和线条嘴。
- 两片不对称叶片天线，表现生长与充能，不使用猫耳或尾巴。
- 杏色圆角机身、短胶囊臂、深色双足；胸前菱形状态灯，没有口袋或项圈。
- 高光、渐变和落地阴影提供轻立体感；不是下载的 3D 模型，也不宣称使用了真正的 3D 渲染器。
- 快报图标改为叶片，界面改用“芽芽智能体”“芽芽快报”，旧桌面文件名仅保留启动兼容。

## 动态与布局

状态由实际账户额度和既有 Tibo 状态机驱动：正常、专注、谨慎、告急、预告、赠送机会和已确认重置分别反馈。赠送机会不等于额度已经重置。

保留独立手臂、眨眼、轻呼吸、点击反馈、重置跳跃与胸灯脉冲；关闭系统界面动画时不启动新的角色动作。额外预留抬手、旋转、放大与跳跃余量，保持 43×64 DIP 视口，不扩大整个组件。

自动测试检查形状结构、各状态反馈、动作边界，并渲染实际界面的 100%/150%/200% 图片供人工观察。结构测试不是法律上的相似性鉴定。
